# 页面与数据状态规范

从页面的数据来源、操作和现有内容出发，逐个判断状态是否可达。分别定位整页、列表尾部、单个字段或提交按钮的反馈。已有数据刷新时说明是否保留旧内容及如何提示更新。

只覆盖适用场景。区分首次加载与追加加载、从未创建与筛选无匹配、首次失败与已有内容后失败。对长列表说明取数触发点、结束条件、重复请求和过期结果的处理；分页参数有依据再给值。

为失败、返回、切换筛选和提交重试明确保留的输入、条件、已加载项与滚动位置。缺省图标出语义、位置和已有素材；待设计的素材单独标记。

输出「区域｜触发条件｜显示内容｜可用操作｜保留数据与恢复结果」。示例：第二页超时，保留第一页和当前位置，仅在尾部显示重试；重试成功后按稳定标识追加去重。
