# 参考页面拆解

不适用：为本项目产出新视觉方向或生图提示词改用 `ui-concept-brief`。

## 步骤

1. **界定范围**：以用户指定的平台、页面、任务和关注区域为准；未指定关注区域时先询问。
2. **选取案例**：先看用户给的来源。需要同类案例时，按同平台、同任务、同状态查找；App 优先使用可用的 Mobbin MCP，不可用时用其他可访问的来源并说明。写明每个案例解决的是什么相同问题。
3. **分层记录**：依次记录「可见事实 → 交互证据 → 迁移建议」，不要混写。
4. **证据边界**：
   - 静态截图只能说明层级和状态外观；
   - 验证触发、返回或过渡需要操作记录或连续画面；
   - 动效时长只有可测量时才给数字；
   - 无法访问的来源写明缺口。
5. **配图**：每个关键模式附一张真实参考图或局部截图，标明产品、页面、区域与原始链接。只有链接时标记「缺图」；生成的概念图不能充当原站证据。

## 输出

使用 Markdown 表格：

| 参考图与来源 | 观察到的行为或布局 | 适用条件 | 在当前项目的用法 |
| --- | --- | --- | --- |
| 产品·页面·区域·链接 | 录屏显示关闭筛选层后滚动位置保留 | 长列表 + 筛选 | 可迁移；是否缓存请求仍待验证 |
