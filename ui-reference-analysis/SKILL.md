# 参考页面拆解

以用户指定的平台、页面、任务和关注区域界定观察范围。先看用户给的来源；需要同类案例时，按同平台、同任务、同状态查找，App 优先用可用的 Mobbin MCP。说明每个案例解决了什么相同问题。

依次记录可见事实、交互证据和迁移建议。静态截图可以说明层级和状态外观；验证触发、返回或过渡需要操作记录或连续画面。动效时长只有可测量时才给数字。无法访问的来源写明缺口。

每个关键模式附一张真实参考图或局部截图，标明产品、页面、区域与原始链接。仅有链接时标记“缺图”；生成的概念图不能充当原站证据。

按「参考图与来源｜观察到的行为或布局｜适用条件｜在当前项目的用法」输出。示例：录屏显示关闭筛选层后滚动位置保留，可迁移到长列表；是否缓存请求仍待验证。
