# 视觉初稿提示

提取目标平台、用户第一眼要理解的任务、首要操作、真实业务示例和已有品牌约束。材料不足时用明确标注的示例文案。默认输出提示词；用户要求生图时再调用可用的生图工具。

比较首页方向时，默认给三案，用户指定数量优先。保持用户、业务内容和视口可比，用主视觉、信息顺序、内容密度或布局形成差异。沿用现有品牌；需要提案色时，用按钮、选中和链接展示色彩用途。

每案给一段可独立复制的提示词，写全平台与画幅、首屏标题、核心操作、布局、可见示例数据、字体层级和色彩作用。旁列相关真实页面图、来源、借鉴区域与选择理由。参考缺失写明缺口。

交付到当前页面的决策点，可选择、混搭或换一批。保留用户认可的部分。示例：同一订单查询页分别突出搜索入口、最近订单、异常订单；三案使用相同订单数据。
