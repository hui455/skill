# 已有流程走查

固定角色、入口、任务终点和材料版本。沿用户已有路径逐边核对「从哪里、做什么、到哪里、如何确认成功」。材料只有页面清单时，标出无法判定的跳转；未提供流程时请用户给出草图或最短路径。

检查该任务可达的取消、返回、中断、失败重试及再次进入。区分确认的断点和材料未覆盖的分支；不要自行重排用户的业务流程。遇到多个合理业务策略时写出需要决定的问题。

标注每条证据为静态走查或实际操作，给出节点名、画板位置或复现步骤。按是否阻断主任务、导致数据丢失或仅增加操作成本排序。

输出「路径与触发动作｜当前结果及证据｜影响｜建议补充的最小设计｜验收条件」。示例：编辑草稿后按返回，流程图只画了保存成功分支；草稿处理规则待确认，实机行为未知。
