# 公共组件规范

限定组件与平台，先复用现有名称、变量和变体。给数值注明来自设计文件、估算或建议。按文字、表面、边框、动作和反馈定义语义色；有多主题才补每套映射。区分禁用、只读和忙碌。

每个组件写清用途、结构、内容边界和适用变体。根据输入方式选状态：键盘焦点与指针悬停用于支持它们的界面，触屏描述按压和返回。标出长文本、动态字号及无障碍名称如何处理。

对覆盖层说明打开后的焦点、遮罩点击、Esc 或系统返回、提交中能否关闭，以及关闭后焦点回到哪里。业务尚未决定的关闭策略列为待定。

输出「部件或变量｜变体或状态｜外观｜输入与反馈｜可验证条件」。示例：保存按钮提交中维持宽度、显示进度并阻止重复提交；出现错误后恢复可重试操作。
